# objective
We understand how to handle missing or null values in a dataset using PySpark DataFrames. Real-world datasets often contain incomplete data, so it is important to understand how to clean and preprocess such data before further analysis.

In this exercise, we perform two common null-handling operations:
1. Removing rows with missing salary values
2. Replacing missing age values with a default value

# Learnings

- Understanding null values in Spark DataFrames
- Removing rows containing null values using `dropna()`
- Filling missing values using `fillna()`
- Applying multiple transformations sequentially on a DataFrame
- Basic data cleaning techniques used in data engineering pipelines

# Observations

Handling null values is an essential step in data preprocessing. Removing invalid records and filling missing values ensures that downstream transformations and analytics operate on clean and consistent datasets.
