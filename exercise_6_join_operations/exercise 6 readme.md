# objective

Here we learn how to combine multiple datasets using join operations in PySpark. Two datasets (employees and departments) are joined using a common column to create a unified dataset.

## Steps to run

spark-submit exercise_6_join_operations/operations.py

# Learnings

- Understanding relational joins in Spark
- Performing inner joins between DataFrames
- Combining datasets using a common key
- Working with multiple CSV files in a Spark pipeline

# Observations

Join operations are fundamental in data engineering pipelines where data from multiple sources must be combined. Spark efficiently performs joins across distributed datasets, enabling scalable data processing.
