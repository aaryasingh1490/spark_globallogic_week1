# Objective

This exercise demonstrates basic data cleaning techniques in PySpark. The dataset contains inconsistent values in the department column, which are standardized using transformation functions.

# Steps to run

spark-submit exercise_8_data_cleaning/data_cleaning.py

# Learnings

- Using withColumn() to transform existing columns
- Applying string transformations such as upper() and trim()
- Standardizing inconsistent data values
- Basic data cleaning operations used in ETL pipelines
